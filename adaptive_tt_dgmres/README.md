# 学习型自适应 TT-DGMRES：首个可运行版本

这里的 DGMRES 指 Drazin 逆求解算法。这个目录是独立的研究原型，既有固定参数论文实验保留原样。

模型采用 **共享 TT 接口 MLP → 均值/最大池化 → 全局状态 MLP → GRU64 → 联合动作评分**，共约 4 万参数。
每个周期选择 `(重启长度 m, 局部误差预算比例 alpha)`，周期内部动态分配各次 TT-round 的容差。

本次成功运行归档：`results/adaptive_tt_dgmres_guarded_run_20260926/`。27 项测试通过，两个留出算例通过残差和值域验收。
这批小样本模型本身持续偏好短重启，最终成功依赖进展回退；总耗时仍高于固定参数基线。
没有进展回退的失败结果保留在 `results/adaptive_tt_dgmres_first_run/`，未覆盖。

## 运行

从项目根目录执行：

```powershell
python -m adaptive_tt_dgmres --output results/adaptive_tt_dgmres_first_run
```

环境已验证：Python 3.9、PyTorch 2.7 CPU、tntorch。程序只使用 CPU，默认一个计算线程；不需要下载模型。
首次运行会采集实际求解轨迹、训练小网络、保存并重新加载权重、在留出的算例上比较求解结果。
小样本训练的目的在于跑通流程，默认参数不是正式论文实验协议。

同一份数据重新训练：

```powershell
python -m adaptive_tt_dgmres --output results/adaptive_tt_dgmres_first_run --reuse-data --epochs 250
```

`--reuse-data` 要求数值配置和算例划分一致；归档会保留生成数据时的源码哈希。
需要改变容差、迭代上限或采集数量时，请使用新输出目录重新采集。

运行测试：

```powershell
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
python -m pytest adaptive_tt_dgmres/tests -q
```

这里关闭本机无关 pytest 插件的自动加载，以免测试启动卡住。

## 数值含义

- 算例为指标一、已知左右零空间的 Neumann Kronecker 和，包含不同尺寸、阶数及各向异性系数。
- 当前解始终经过已有的值域投影；终止还要独立重算 `||b-Ax||/||b||`，并检查值域偏离。
- 参考解只用于最终评价，不作为模型输入、动作选择或验收条件；参考解评价耗时不计入在线求解时间。
- 每次算法舍入记录请求容差、实际有效容差、实测舍入误差、秩和审计耗时。硬秩上限导致容差不可达时显式拒绝。
- 算法内部的残差舍入使用算法容差；独立诊断的舍入精度单独固定。最终真实残差直接对未截断的 `b-Ax` 求稳定 TT 范数。
- 局部预算是**各次局部相对舍入误差的未加权和**，属于经验控制。它尚不包含推导出的传播权重，不能称为变换残差误差认证或收敛保证。
- 学习策略含实测进展回退：最近两个周期的残差下降预计不能在剩余迭代预算内达标时，转为候选中的最长重启和最小误差预算。日志分别保留网络提案、实际动作、回退原因；这也不是全局收敛证明。`--disable-progress-guard` 可用于消融。
- 浮点审计会单独记录舍入噪声余量；这不是区间算术认证。参考解误差和残差是不同指标。

## 训练标签与范围

从相同 TT 状态尝试 6 个联合动作：`m ∈ {4, 8, 12}`、`alpha ∈ {0.1, 1.0}`。
首个周期后使用固定后续策略，记录整个分支达到目标的时间。标签包含续跑初始化，首帧特征已缓存，
所以是**缓存首帧的分支续跑成本**，仅作为在线剩余时间的预训练替代量；不是最优动作 oracle。
失败分支显式加罚并保留原始原因。训练、验证、测试按完整算子实例分开。

本版本没有完成完整策略迭代、跨问题族训练、高指数 Drazin 情形或加权误差传播定理。
单次 CPU 测时不能支持加速结论。每次舍入的审计和额外谱特征提取也可能让学习版本更慢，所有这些在线成本都已计入。

## 文件分工

- `backend/`：现有 v4 求解器的隔离副本，`provenance.json` 记录来源与哈希。
- `solver.py`：动态周期接口、逐次舍入接口、独立诊断和初始解续跑。
- `features.py`：不展开完整张量的物理切分奇异谱特征，处理 TT 表示的规范自由度。
- `rounding.py`：经验预算分配与实际舍入误差审计。
- `model.py`：共享编码器、GRU、联合动作评分、辅助预测头及权重读写。
- `controller.py`：在线状态和周期决策，禁止使用参考解信息。
- `experiment.py`：实际轨迹采集、预训练、固定参数调优、留出测试和结果归档。

下一阶段应先量化舍入审计/特征提取的成本，增加完整轨迹策略改进，再研究可计算的误差传播权重与验收上界。
